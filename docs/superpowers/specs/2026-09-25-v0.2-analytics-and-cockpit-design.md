# v0.2 — TTM valuation, reconstructed history, cockpit integration

**Date:** 2026-09-25 · **Status:** approved in conversation · **Builds on:** `2026-09-25-financial-data-collector-design.md`

## 1. Goals

1. Turn stored statements into chartable numbers: trailing-twelve-month figures and daily valuation ratios per holding.
2. Extend the portfolio timeline back to the first recorded transaction (July 2024) by replaying transactions against prices, with cost-basis lots and realized gains.
3. Make the investing cockpit a consumer of this database: it reads prices, dividends and fundamentals written by this project and stops fetching them itself.

Out of scope: time-weighted/money-weighted returns, split adjustment of replayed units (flagged by reconciliation instead), moving investing's filings/earnings/insider feeds, any cockpit code change.

## 2. New sync steps

`STEPS = ("ingest", "prices", "sec", "derive", "export")`.

- **derive** rebuilds every derived table from scratch each run, in one transaction per table: `holdings_daily`, `cash_daily`, `lots`, `realized_gains`, `reconciliation`, `valuation_daily`. Pure database work, no network; a few seconds for a 40-symbol book.
- **export** writes the cockpit feed files when `[export.cockpit] enabled = true` and the target directory exists. Skipped (status `skipped`) otherwise.

## 3. Schema additions (migration `0003_derived.sql`)

**`holdings_daily`** — `as_of_date, account_id, symbol, units, close, market_value, basis` (`snapshot` | `reconstructed`), PK `(as_of_date, account_id, symbol)`.
**`cash_daily`** — `as_of_date, account_id, amount, basis`, PK `(as_of_date, account_id)`.
**`lots`** — `id, account_id, symbol, open_date, units_open, units_left, cost_total, cost_per_unit, source_tx_id`. Open lots are rows with `units_left > 0`.
**`realized_gains`** — `id, account_id, symbol, sell_date, units, proceeds, cost_basis, gain, first_lot_date, holding_days, cost_known` (0 when a sale exceeded recorded lots).
**`reconciliation`** — `as_of_date, account_id, symbol, projected_units, snapshot_units, diff`: dates where the replay reaching a real snapshot disagrees with it by more than 1e-6 units.
**`valuation_daily`** — `symbol, date, close, shares, market_cap, revenue_ttm, net_income_ttm, ocf_ttm, fcf_ttm, eps_ttm, pe, ps, p_fcf, dividends_12m, dividend_yield, ttm_period_end, available_from`, PK `(symbol, date)`.

Views:
- `financial_line_items_ttm` (static SQL): per `cik, line_item, period_end` over quarter rows. Flow kinds (`duration`, `per_share`) are the sum of the four most recent quarters ending at `period_end` when the first and fourth quarter ends are 240–300 days apart (three quarters, so a gap breaks the window); instant kinds (`instant`, `shares`) are the row's own value. Carries `n_quarters`, `available_from = MAX(filed)` over the window.
- `financials_ttm` (generated with the other wide views): one row per `cik × period_end` with one column per line item, `fcf` and margins, `symbol`, `company`, `available_from`.
- `valuation_latest`: the newest `valuation_daily` row per symbol.
- `portfolio_daily_full`: `as_of_date, holdings_value, cash, total, fidelity_total, basis` from `holdings_daily` + `cash_daily` (basis is `snapshot` when every account that day came from a snapshot, else `reconstructed`).

## 4. Derivation rules (`derive/history.py`, `derive/valuation.py`)

**Calendar.** Every date from the earliest transaction or snapshot to the latest price date, restricted to dates that have at least one price row (trading days).

**Units.** Per account × symbol, walk dates in order. Rows with a symbol and non-null units of type `buy`, `sell`, `reinvest`, `transfer`, `other` change units by `units` (sign included). On a date with a real `position_snapshots` row for that account, units are **re-anchored** to the snapshot (and every symbol the snapshot omits goes to zero). Before the first snapshot the walk starts from zero. `holdings_daily.basis` is `snapshot` on anchor dates, else `reconstructed`. Rows with zero units are not written.

**Close.** `prices.close` on the date, else the last close on or before it; `market_value = units × close`; NULL close gives NULL value.

**Cash.** Per account: running sum of every transaction `amount` (all types), re-anchored to `cash_balances.amount` on snapshot dates. Before the first snapshot the sum starts at zero, which is exact only for accounts whose history begins at opening (true for the owner's Fidelity accounts, not for Webull; the basis column and README say so).

**Lots and realized gains.** FIFO per account × symbol. `buy` and `reinvest` open a lot: `cost_total = -amount` when amount is present, else `units × price`, else 0 with `cost_known` false. `sell` consumes lots oldest first; proceeds = `amount` (or `-units × price`); gain = proceeds − cost of the units consumed; a sale that exceeds recorded lots is recorded with `cost_known = 0` and NULL gain for the uncovered part. Lots are not re-anchored to snapshots (a snapshot has no cost basis per lot); the `reconciliation` table is the warning light.

**Reconciliation.** On each snapshot date, before re-anchoring, compare the projected units with the snapshot's; write a row when they differ.

**Valuation.** For each symbol with a CIK and at least one `financials_ttm` row: for each price date, take the TTM row with the greatest `available_from ≤ date`. `shares` = that row's `shares_outstanding` else `shares_diluted`. `market_cap = close × shares`; `eps_ttm` = TTM `eps_diluted` when built from four quarters, else `net_income_ttm / shares`; `pe = close / eps_ttm` when `eps_ttm > 0`; `ps = market_cap / revenue_ttm` when revenue > 0; `p_fcf = market_cap / fcf_ttm` when fcf > 0; `dividends_12m` = sum of `prices.dividend` over the trailing 365 days; `dividend_yield = dividends_12m / close`.

## 5. Cockpit integration

**Universe.** `[sources.investing] content_dir = "../investing"` (owner only; ignored when missing) adds every `ticker:` frontmatter value in `theses/*.md` and `watchlist/*.md`, and every non-comment line of `basket.txt`, to `securities` (asset type unknown), so they get prices and SEC statements.

**Export** (`[export.cockpit] enabled = true`, `dir = "../investing/data"`). Written atomically (temp file, then replace), only when the serialized content differs from the existing file:

- `prices.json`: `{as_of, source, lookback_days: 1826, sources: {T: source}, by_ticker: {T: [{d, c: adj_close}]} (ascending, last 1826 days), misses: [universe symbols with no price rows]}`.
- `dividends.json`: `{as_of, source, history_from: <5 years ago>, by_ticker: {T: [{d, amt}]}, misses: []}` where `amt` is `prices.dividend` divided by the product of every later `split_factor` (investing's split-adjusted rule); tickers with no dividends get an empty list.
- `fundamentals.json`: `{as_of, source, lookback_years: 10, by_ticker: {T: {company_name, annual: [...], quarterly: [...]}}, misses: [...]}`. `annual`: the last ten `financials_annual` rows oldest→newest with keys `fy, revenue, gross_profit, operating_income, net_income, ocf, capex, assets, liabilities, cash, shares_diluted, eps_diluted, dividends_paid, buybacks, fcf, gross_margin, operating_margin, net_margin, fcf_margin` (`assets`/`liabilities` map from `total_assets`/`total_liabilities`; missing values are `null`). `quarterly`: the last nine `financials_quarterly` rows oldest→newest with `end, revenue, net_income, eps_diluted, shares_diluted`. `misses`: universe symbols that are funds or have no line items.

**Investing side.** `pipeline/refresh-launch.ps1` passes `--skip prices,fundamentals` to `refresh_all.py`, with a comment pointing here. Nothing else in investing changes; the cockpit keeps reading the same files.

**Verification before the switch.** Export to a temporary directory and compare with investing's current files: identical key sets, identical last close for every overlapping ticker (both are Tiingo adjusted closes), identical latest annual revenue and net income for every overlapping company.

## 6. CLI

`fdc sync` runs the two new steps. `fdc export [--dir PATH]` runs only the export (for a dry check into another folder). `fdc status` reports them like any step.

## 7. Tests

Synthetic fixtures only, as before. Required: TTM window math (four consecutive quarters, gaps excluded, instants pass through); valuation point-in-time selection (a filing dated after the price date is not used) and each ratio's NULL rules; replay units with re-anchoring, zero-units suppression, forward-filled closes; cash anchoring; FIFO lots across partial sells and a sale exceeding lots; reconciliation row on drift; export files match the documented key sets and orderings, dividends split-adjusted, atomic write skipped when unchanged, export skipped when the directory is missing; investing universe parsing of frontmatter and basket.
